## 2. Описание реализации и сложность алгоритмов

### Графы
- **Представление:**
  - *Матрица смежности* — квадратная матрица размером `V × V`, где `A[i][j] = 1`, если существует ребро между вершинами `i` и `j`.
  - *Матрица инцидентности* — матрица размером `V × E`, показывающая, какие вершины инцидентны каждому ребру.
  - *Список смежности* — используется внутри алгоритма обхода для эффективного доступа к соседям.
- **Алгоритм:** поиск компонент связности реализован через **DFS (поиск в глубину)** с использованием стека.
- **Сложность:**
  - Построение матрицы смежности: `O(V²)`
  - Построение матрицы инцидентности: `O(V · E)`
  - Поиск компонент связности (DFS): `O(V + E)`

### Бинарное дерево поиска (BST)
- **Структура:** классическое BST на указателях — каждый узел (`Node`) хранит значение и ссылки на левого и правого потомка.
- **Операции:**
  - `insert` — рекурсивная вставка с соблюдением свойства BST.
  - `search` — рекурсивный поиск по ключу.
  - `delete` — удаление узла; в случае двух потомков узел заменяется минимальным элементом правого поддерева (приемник).
- **Сложность:**
  - В среднем: `O(log V)` на каждую операцию.
  - В худшем случае (вырождение в список): `O(V)`.

### Пирамидальная сортировка (Heap Sort)
- **Структура:** двоичная max-куча, представленная одномерным массивом.
- **Алгоритм:**
  1. Построение кучи (`heapify`) за `O(V)`.
  2. `V` раз корневой элемент (максимум) меняется местами с последним элементом текущей кучи, после чего свойство кучи восстанавливается для уменьшенной кучи.
- **Сложность:** `O(V · log V)` во всех случаях (лучшем, среднем и худшем).
